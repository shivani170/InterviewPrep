The Factory Pattern is a Creational Design Pattern 
that provides a single place to create objects.

The Abstract Factory Pattern is a creational pattern that creates families 
of related objects without specifying their concrete classes.


Factory vs Abstract Factory
Factory Pattern	                 Abstract Factory Pattern
Creates one type of object	     Creates a group/family of related objects
Example: Create EmailService or SmsService	Example: Create Windows Button + Windows Checkbox together
One factory method	             Multiple factory methods
